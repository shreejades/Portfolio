# Shreeja Portfolio

A static portfolio website tailored for a UX Researcher and Designer role.

## Files

- `index.html` — main portfolio page
- `styles.css` — responsive portfolio styling
- `script.js` — smooth scrolling for navigation links

## How to use

1. Open `index.html` in a browser.
2. Share the folder or archive it for vendor review.
3. Update the contact email and project details as needed.

## Notes

This portfolio emphasizes:
- evidence-based research
- mixed-methods user insights
- journey-driven wireframe delivery
- enterprise and public service design experience
